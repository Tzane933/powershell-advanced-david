Orginal Script VS My Script
The orginal script was very much basic at its root, and it lacked a lot especially in validation, error handling and even proper logging. The final script is more improved and makes it more reliable and even easier to maintain

Three improvements I have added is Parameter validation so it prevents invalid resources group nameas, also proper error handling to make troubleshooting easier for everyone. And finally proper logging so we can keep record of the script and how it was executed.

I honestly believe the most valuable improvement that I added was the error handling, it just makes everyones life a lot easier because you can identify the issues and troubleshoot it if the script fails.

The easiest improvement I added was just the documentation, which is pretty obvious why, its just typing what things do in and explain the parameters and more.
